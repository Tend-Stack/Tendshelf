Shows where you are in a book that has both audio and text. One position is the rule; it splits only when you read ahead in Read mode, or scroll ahead in Read along.

- A filled dot is the voice; a ring is you. Each has a word in the legend, so shape and words carry it, not colour.
- When the two differ, the book page and the player offer one choice: "Continue from page 246" or "Continue from 14:06". The newer one is first.
- `role="progressbar"` with `aria-valuetext` in words: "62 percent, chapter 12, page 214 of 346".
