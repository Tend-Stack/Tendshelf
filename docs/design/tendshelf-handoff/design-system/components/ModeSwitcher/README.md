Switches how you follow one book. It never changes your place: all three modes share one position.

- `role="radiogroup"` with three `role="radio"` buttons; arrow keys move and select. On desktop, R cycles the modes.
- Top bar style (`.ts-mode`) in the reader; block style (`.ts-mode--block`) on book pages.
- Listen opens the normal player. Read along keeps the voice and shows the text with the highlight. Read pauses the voice and leaves the text.
- When a book has no ebook, Read along and Read are disabled and the book page offers "Add an ebook" beside it. While alignment is still running, Read along works for the chapters that are ready and the book page says how far it goes ("Read along works up to chapter 8 for now"); Read works for the whole book.
