The same player as Listen, folded so the text gets the screen. It shares the audio element and position with the mini-player and full player.

- In read-along, skip buttons move by sentence (desktop: J and K; ← and → still skip 30 s). The play button and scrubber take the cover accent, as in the full player.
- Times show the page and "left in chapter" instead of clock time; the full player is one swipe up.
- `hx-preserve` like the mini-player; it never reloads when the chapter partial swaps.
