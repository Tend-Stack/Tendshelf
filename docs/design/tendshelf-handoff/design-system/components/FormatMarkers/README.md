Says what a book has: an audiobook, an ebook, or both aligned for read-along.

- On book pages, chips sit under the title. "Read along" (ember outline) means the two are paired and aligned.
- On cover grids, a 26px badge in the bottom-right corner shows only for read-along books, with an `aria-label`. Audio-only books get no badge; that's the norm.
- "No ebook" (dashed) only appears for the book's owner, beside "Add an ebook".
