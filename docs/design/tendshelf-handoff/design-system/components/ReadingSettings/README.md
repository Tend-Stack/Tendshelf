Opens from the Aa button in the reader. Every change applies to the preview at the top and to the page behind the sheet at once; there is no Save.

- Rows: Theme (Dark, Light, Sepia, Contrast), Text size (18, 20, 22; large-text mode adds 26), Line spacing (Compact, Normal, Airy), Font (Serif or Sans, below the fold), Highlight (Wash, Underline, Brighten), Word underline, Follow the voice, and the view: Page or Focus line.
- Each choice row is a `role="radiogroup"`; the switches are `role="switch"`. The preview is `aria-hidden`; the page behind already shows the change.
- Settings are saved on the server per person and follow them across devices. Theme here also changes the app's theme.
