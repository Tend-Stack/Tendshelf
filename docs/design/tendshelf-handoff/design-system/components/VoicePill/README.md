Appears when the sentence being spoken leaves the view because you scrolled or turned pages. Tapping it scrolls back and resumes following.

- Centred, 16px above the read-along dock. Fades and rises 8px in over `duration-pill` (200ms); leaves when the voice is back in view.
- While it shows, the reader stops auto-scrolling, so you can read ahead in peace. The voice keeps playing.
- Keyboard: F on desktop. It's a real link with the page in its name: "Back to the voice, page 214".
