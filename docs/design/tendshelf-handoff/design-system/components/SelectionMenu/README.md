Floats 8px above the selection (below it when there's no room), and never covers the selected words.

- `role="toolbar"` with an `aria-label`; arrow keys move between items; Esc dismisses and keeps the selection.
- New selection: Highlight, Note, Listen from here, Copy. Tapping an existing highlight: Add note (or Edit note), Remove highlight.
- "Listen from here" moves the voice to the start of the selected sentence. In Read mode it also switches to Read along.
- Copy is limited to what the server allows for the book; if a book is copy-protected, Copy is left out rather than disabled.
