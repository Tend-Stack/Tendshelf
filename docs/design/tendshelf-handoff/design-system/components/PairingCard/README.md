Asks the owner to confirm that an ebook and an audiobook are the same book before alignment runs.

- Checks are plain sentences with an icon each: green check for a match, gold warning for a difference that still works.
- Primary: "Pair and prepare read-along". Quiet: "Not the same book", which keeps the ebook as its own book.
- When nothing matches, the card says "Choose the audiobook" and opens a search of the shelf instead.
- Copy-protected file: a `role="alert"` card with the shield icon, "This ebook is copy-protected", and "Choose another file". Nothing is stored. The audiobook keeps working.
