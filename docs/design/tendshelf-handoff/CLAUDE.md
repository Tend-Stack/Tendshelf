# Tendshelf design handoff

Read `AGENTS.md` and follow it; it applies to Claude Code too. The short version:

- Start with `README.md`, then `docs/HANDOFF.md` (the rules) and `design-system/BRAND.md`.
- Styles come from `design-system/tokens.css` and `design-system/components/bundle.css`; no hard-coded colours, no inline styles in the app.
- Screens are in `screens/` (`screens/INDEX.md` lists all 114). PNGs show the target; `.html` snapshots show the markup, roles and copy.
- `docs/HANDOFF.md` wins when sources disagree.
- No TV layouts, and nothing from `screens/directions/`.
