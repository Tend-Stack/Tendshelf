# Screen index

Every design board, rendered. Each has a `.png` (what it should look like) and a `.html` (a static snapshot of its markup using the design system classes). Sizes are the design size in CSS pixels; phone boards taller than 844 show the full scroll.

Boards named `…Light`, `…Sepia` or with a `theme` are the same screen in another theme. Parts (names starting with "Part") are reusable pieces shown on their own.
