## Invariants (all packages)
1. Book text spoken aloud reaches only `AVSpeechSynthesizer` with an on-device voice that is not a Personal Voice; it is never logged (a length only), stored or sent back.
2. A scanned code is untrusted text: it goes only to `ConnectFlow.onLink` (shared `parseHandoff`, then the address confirmation); nothing is requested before the person confirms. No server page offers an iPhone browser a `tendshelf:` address.
3. The widget extension makes no network request, links no `TendshelfShared`, holds no token, and reads only `widget/state.json` and `widget/cover.jpg` in the app group. Sign-out leaves no title or cover there.
4. CarPlay and widget commands reach the same `Playback` the page drives; CarPlay lists use the device token through `PlayerApi` to the pinned origin only, with the car words for every failure.
5. Linux, Android and browsers are unchanged except: `native-speech.js` loads for `ios`; two pair/invite sentences for iPhone Safari; `Nav.Scan` (Android ignores it); the moved car functions (same output).
6. No certificate, profile, App ID or account is created by code or agent. `archive.sh` signs only from the operator's file and exits with words when it is missing.
7. `MARKETING_VERSION` is plain `YEAR.RELEASE.FIX`; `CFBundleVersion` is Android's versionCode (`year*100000+release*1000+fix`), optionally `.<n>` for a re-upload; both rise with every release.
8. Simulator checks use a throwaway server (`TS_TEST_BIND=$(tailscale ip -4) android/tools/test-server.sh 8098 .local/tests/ios/<pkg>/<run>`), never port 8095 or the operator's accounts; the run folder is removed after recording.
